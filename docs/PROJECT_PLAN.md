# Quant Auto Trade 전체 계획

_2026-11-25 · 기획안(사용자 문서)의 요약. 결정이 바뀌면 이 파일을 고친다._

## 목표
1. **오늘 현황**: 아침에 앱을 열면 밤사이 미국 장·오늘 한국 장·관심종목에 무슨 일이 있었는지 3분 안에 파악한다.
2. **주요 뉴스**: 한·미 시장 뉴스와 관심종목 뉴스·공시를 중복 없이 추려 보여 준다(규칙 기반, 유료 AI 없음).
3. **기준선 초과**: 원화 환산·세금·수수료를 뺀 뒤 '미국 상장 S&P 500 ETF를 사서 그냥 두기'보다 나은 전략만 실제 돈을 쓴다. 수익률이 비슷해도 낙폭이 훨씬 작으면 성공으로 본다.

## 사용자 결정 (2026-11-25)
- 미국 중심. 기준선은 미국 상장 S&P 500 ETF 보유. 개별주와 ETF는 같은 잣대로 둘 다 검증해 잘 되는 쪽을 쓴다. 한국은 현황·뉴스용.
- 저장소는 공개. 내부 데이터(계좌·잔고·주문·전략 결과)는 DB에 따로 두고 토큰으로 접근한다.
- DB는 무료(Neon). 파일 보관소는 Cloudflare R2(무료 범위).
- 뉴스 요약에 유료 AI를 쓰지 않는다.
- 기존 Quant_Manager_App(GCP)은 새 앱이 다 끝난 뒤 끈다.

## 구조
수집(Python, GitHub Actions 정기 실행) → 저장(R2: 원본·전체 이력 Parquet / Postgres: 화면·전략이 매일 읽는 표) → 분석(Python: 지표·브리핑·백테스트·신호) → 화면(Next.js, Vercel: 오늘·시장·종목·전략·계좌) → 매매(KIS 주문, 서버에서만, 모의투자 먼저).

## 데이터 소스 (1순위 → 예비)
| 데이터 | 1순위 | 예비 |
| --- | --- | --- |
| 미국 일봉 | KIS 해외주식 기간별시세 | Tiingo EOD → yfinance |
| 한국 전종목 일봉·ETF | KRX OPEN API | 공공데이터포털(금융위원회 주식시세·증권상품시세) |
| 한국 관심종목 장중·수급 | KIS 국내주식 | — |
| 미국 뉴스 | Finnhub | Tiingo 뉴스 |
| 한국 뉴스 | 네이버 검색 API(뉴스) | — |
| 공시·재무 | OpenDART, SEC EDGAR | Finnhub |
| 매크로·환율 | ECOS, FRED | KIS 환율 |

pykrx·FinanceDataReader의 KRX 경로는 KRX가 로그인을 요구하도록 바뀌어 쓰지 않는다(비밀번호 스크래핑 금지).

## 검증 절차 (모든 전략 공통)
- 그날까지 알 수 있었던 값만 쓴다(재무는 공시일, 매크로는 발표일). 신호는 다음 거래일 체결.
- 상장폐지 포함 유니버스, 수정주가 일관 적용, 수수료·환전·세금 반영한 원화 성과.
- 개발 → 검증 → 홀드아웃(한 번만) 구간. 시도한 조절값 개수를 기록.
- 통과하면 KIS 모의투자로 최소 3개월, 그다음 소액 실전.
